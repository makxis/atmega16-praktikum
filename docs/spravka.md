# Справка

Шпаргалка: регистры, формулы, коды сегментов и готовые таймерные числа для «Контроллера ПУ» (ATmega16A, 8 МГц). Подробности и объяснения в главах, ссылки стоят у каждого раздела.

## Регистры

### Порты: DDRx, PORTx, PINx

| DDRx (бит) | PORTx (бит) | Что на выводе |
|---|---|---|
| 1 | 0 | выход, уровень 0 |
| 1 | 1 | выход, уровень 1 |
| 0 | 0 | вход без подтяжки: если ничего не подключено, «висит» и читается случайно |
| 0 | 1 | вход с подтяжкой к +5 В (если PUD = 0): отпущенная кнопка читается как 1 |

PINx: фактический уровень на выводах, читать можно и у входов, и у выходов. У ATmega16 PINx только для чтения: запись в PINx вывод не переключает (так умеют более новые AVR). На панель выведены только PC0, PC1, PB2–PB7, PD0–PD7. Подробно: [Регистры DDR, PORT, PIN](04-porty.md#регистры-ddr-port-pin), [Подтяжка и бит PUD](04-porty.md#подтяжка-и-бит-pud).

### Биты служебных регистров

В заголовке столбца номер бита, 7 старший. «нет»: бит не используется и читается как 0.

| Регистр | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|---|---|---|---|---|---|---|---|---|
| SREG | I | T | H | S | V | N | Z | C |
| SFIOR | ADTS2 | ADTS1 | ADTS0 | нет | ACME | PUD | PSR2 | PSR10 |
| MCUCR | SM2 | SE | SM1 | SM0 | ISC11 | ISC10 | ISC01 | ISC00 |
| MCUCSR | JTD | ISC2 | нет | JTRF | WDRF | BORF | EXTRF | PORF |
| GICR | INT1 | INT0 | INT2 | нет | нет | нет | IVSEL | IVCE |
| GIFR | INTF1 | INTF0 | INTF2 | нет | нет | нет | нет | нет |
| TIMSK | OCIE2 | TOIE2 | TICIE1 | OCIE1A | OCIE1B | TOIE1 | OCIE0 | TOIE0 |
| TIFR | OCF2 | TOV2 | ICF1 | OCF1A | OCF1B | TOV1 | OCF0 | TOV0 |
| TCCR0 | FOC0 | WGM00 | COM01 | COM00 | WGM01 | CS02 | CS01 | CS00 |
| TCCR1A | COM1A1 | COM1A0 | COM1B1 | COM1B0 | FOC1A | FOC1B | WGM11 | WGM10 |
| TCCR1B | ICNC1 | ICES1 | нет | WGM13 | WGM12 | CS12 | CS11 | CS10 |
| TCCR2 | FOC2 | WGM20 | COM21 | COM20 | WGM21 | CS22 | CS21 | CS20 |
| ASSR | нет | нет | нет | нет | AS2 | TCN2UB | OCR2UB | TCR2UB |
| ACSR | ACD | ACBG | ACO | ACI | ACIE | ACIC | ACIS1 | ACIS0 |

Имена битов в `<avr/io.h>` равны их номерам: `(1<<PUD)` это `(1<<2)`. Флаги в GIFR и TIFR сбрасываются записью 1: `TIFR=(1<<TOV0);`. Пишите `=`, а не `|=`: `|=` запишет 1 во все поднятые флаги регистра и сбросит их тоже.

| MCUCSR | JTRF, WDRF, BORF, EXTRF, PORF | причина последнего сброса: JTAG, сторожевой таймер, просадка питания, кнопка «Сброс», включение | |

| TCCR1A, TCCR1B | COM1A, COM1B, WGM13..WGM10, CS12..CS10, ICNC1, ICES1 | то же для Timer1, плюс настройка захвата | [7](07-tajmery.md) |

Значения из программ курса:

| Строка | Что значит |
|---|---|
| `TCCR0\|= (1<<CS01)\|(1<<CS00);` | Timer0: Normal, делитель 64, переполнение раз в 2,048 мс (TCCR0 = 0x03) |
| `TCCR1B\|= (1<<CS12)\|(1<<WGM12);` | Timer1: CTC до OCR1A, делитель 256 (TCCR1B = 0x0C) |
| `OCR1A=31249;` | 31 250 тиков по 32 мкс: совпадение раз в секунду |
| `TIMSK\|= (1<<OCIE1A)\|(1<<TOIE0);` | прерывания: совпадение A Timer1 и переполнение Timer0 (TIMSK = 0x11) |
| `ACSR\|= (1<<ACD);` | компаратор выключен |
| `DDRC=0x00; PORTC=0x02;` | PC1: вход с подтяжкой (кнопка) |

### Делитель: биты CS

Код делителя пишут в биты CSn2, CSn1, CSn0: у Timer0 в TCCR0, у Timer1 в TCCR1B, у Timer2 в TCCR2. Такт таймера равен f_clk / N, f_clk = 8 МГц. У Timer2 коды другие.

| CSn2 CSn1 CSn0 | Timer0, Timer1: делитель N | Timer2: делитель N |
|---|---|---|
| 000 | таймер остановлен | таймер остановлен |
| 001 | 1 | 1 |
| 010 | 8 | 8 |
| 011 | 64 | 32 |
| 100 | 256 | 64 |
| 101 | 1024 | 128 |
| 110 | внешний вход T0 или T1, по спаду (на панель не выведен) | 256 |
| 111 | внешний вход T0 или T1, по фронту (на панель не выведен) | 1024 |

Например, делитель 64 у Timer0 это код 011, `TCCR0|= (1<<CS01)|(1<<CS00);`, а у Timer2 код 100, `TCCR2|= (1<<CS22);`.

## Формулы

f_clk = 8 000 000 Гц, N: делитель, OCR и TOP: числа в регистре сравнения и в вершине счёта, f: частота в герцах. Объяснения и примеры: [Формулы](07-tajmery.md#формулы).

| Что считаем | Формула |
|---|---|
| длительность тика, с | N / f_clk |
| Normal: частота переполнений (TOV, прерывание OVF) | f_clk / (N · 256), у Timer1 f_clk / (N · 65536) |
| CTC: частота совпадений (OCF, прерывание COMP) | f_clk / (N · (1 + OCR)) |
| CTC: частота меандра на выводе OCn (COM = 01) | f_clk / (2 · N · (1 + OCR)) |
| OCR для частоты совпадений f | f_clk / (N · f) − 1, целое и не больше 255 (Timer0, Timer2) или 65535 (Timer1) |
| OCR для меандра частоты f | f_clk / (2 · N · f) − 1, с теми же ограничениями |
| Fast PWM: частота | f_clk / (N · 256), у Timer1 f_clk / (N · (1 + TOP)) |
| Phase Correct: частота | f_clk / (N · 510), у Timer1 f_clk / (2 · N · TOP) |
| заполнение прямого ШИМ | Fast PWM: (OCR + 1) / (TOP + 1); Phase Correct: OCR / TOP |
| сколько раз в секунду обновляется каждый из 4 разрядов индикатора | частота прерываний развёртки / 4 (Timer0, N = 64: 488,28 / 4 = 122 раза в секунду) |

## Коды сегментов

Разводка сегментов во всех программах с индикатором: a = PD0, b = PD1, c = PD2, d = PD3, e = PD4, f = PD5, g = PD6, dp = PD7; бит 1 = сегмент горит. Код символа записывают в PORTD. Коды 0–3 проверены на стенде, остальные посчитаны по той же разводке. Как собирается код и как проверить разводку программой-щупом: [Коды цифр](05-indikator.md#коды-цифр).

```
  f   b
    g
  e   c
    d    dp
```

Готовые массивы:

```c
char kod7[10]={0x3F,0x06,0x5B,0x4F,0x66,0x6D,0x7D,0x07,0x7F,0x6F};
char kodAF[6]={0x77,0x7C,0x39,0x5E,0x79,0x71};  // A b C d E F
```

- Точка добавляется к любому коду через `|`: `kod7[5] | 0x80` даёт «5.».
- Слова: Err = 0x79, 0x50, 0x50; End = 0x79, 0x54, 0x5E; HELP = 0x76, 0x79, 0x38, 0x73.
- Если на вашем индикаторе сегмент зажигается нулём, инвертируйте каждый код: ~0x3F = 0xC0, ~0x06 = 0xF9, ~0x5B = 0xA4 и т. д. Если программа-щуп показала другую разводку сегментов, пересчитайте коды по своей карте битов.

## Таймерные числа при 8 МГц

f_clk = 8 МГц. В ячейках таблиц N означает делитель (его коды в разделе [Делитель: биты CS](#делитель-биты-cs)), OCR: число для регистра сравнения OCR1A, OCR0 или OCR2.

- «ровно»: частота получается точно, деление нацело; если так выходит с несколькими делителями, перечислены все;
- «≈»: точно не получается; дано лучшее приближение (если одинаково хороших вариантов несколько, с наименьшим делителем), получившаяся частота и в скобках погрешность;
- «нельзя (не меньше X Гц)»: сам таймер не даёт частоту ниже X.

### Тик и переполнение

Тик: длительность одного шага счёта, N / f_clk. Переполнение в режиме Normal наступает через 256 тиков у 8-битных таймеров и через 65 536 тиков у Timer1; в скобках частота переполнений.

| Делитель N | У каких таймеров | Тик | Переполнение Timer0, Timer2 (8 бит): период (частота) | Переполнение Timer1 (16 бит): период (частота) |
|---|---|---|---|---|
| 1 | все три | 0,125 мкс | 32 мкс (31250 Гц) | 8,192 мс (122,07 Гц) |
| 8 | все три | 1 мкс | 256 мкс (3906,25 Гц) | 65,536 мс (15,259 Гц) |
| 32 | только Timer2 | 4 мкс | 1,024 мс (976,56 Гц) | нет такого делителя |
| 64 | все три | 8 мкс | 2,048 мс (488,28 Гц) | 524,288 мс (1,907 Гц) |
| 128 | только Timer2 | 16 мкс | 4,096 мс (244,14 Гц) | нет такого делителя |
| 256 | все три | 32 мкс | 8,192 мс (122,07 Гц) | 2,097 с (0,477 Гц) |
| 1024 | все три | 128 мкс | 32,768 мс (30,52 Гц) | 8,389 с (0,119 Гц) |

В программах с индикатором Timer0 с делителем 64 переполняется каждые 2,048 мс (488,28 Гц): по этим прерываниям переключаются разряды.

### Прерывания по совпадению (CTC)

Частота прерываний TIMERn_COMP: f = f_clk / (N · (1 + OCR)). OCR пишется в OCR1A, OCR0 или OCR2.

| Частота | Timer1 (OCR1A до 65535) | Timer0 (OCR0 до 255) | Timer2 (OCR2 до 255) |
|---|---|---|---|
| 1 Гц | ровно: N=256, OCR=31249 | нельзя (не меньше 30,52 Гц) | нельзя (не меньше 30,52 Гц) |
| 2 Гц | ровно: N=64, OCR=62499; N=256, OCR=15624 | нельзя (не меньше 30,52 Гц) | нельзя (не меньше 30,52 Гц) |
| 10 Гц | ровно: N=64, OCR=12499; N=256, OCR=3124 | нельзя (не меньше 30,52 Гц) | нельзя (не меньше 30,52 Гц) |
| 50 Гц | ровно: N=8, OCR=19999; N=64, OCR=2499; N=256, OCR=624 | ≈ N=1024, OCR=155: 50,08 Гц (0,16 %) | ≈ N=1024, OCR=155: 50,08 Гц (0,16 %) |
| 100 Гц | ровно: N=8, OCR=9999; N=64, OCR=1249 | ≈ N=1024, OCR=77: 100,16 Гц (0,16 %) | ≈ N=1024, OCR=77: 100,16 Гц (0,16 %) |
| 488 Гц | ≈ N=1, OCR=16392: 488,01 Гц (0,003 %) | ≈ N=64, OCR=255: 488,28 Гц (0,058 %) | ≈ N=64, OCR=255: 488,28 Гц (0,058 %) |
| 1000 Гц | ровно: N=1, OCR=7999; N=8, OCR=999; N=64, OCR=124 | ровно: N=64, OCR=124 | ровно: N=32, OCR=249; N=64, OCR=124 |

### Меандр на выводе OCn (CTC, переключение)

Вывод OCn переключается при каждом совпадении (COM = 01, вывод настроен на выход битом DDR), поэтому частота сигнала на нём вдвое ниже частоты совпадений: f = f_clk / (2 · N · (1 + OCR)).

| Частота | Timer1 (OCR1A до 65535) | Timer0 (OCR0 до 255) | Timer2 (OCR2 до 255) |
|---|---|---|---|
| 1 Гц | ровно: N=64, OCR=62499; N=256, OCR=15624 | нельзя (не меньше 15,26 Гц) | нельзя (не меньше 15,26 Гц) |
| 2 Гц | ровно: N=64, OCR=31249 | нельзя (не меньше 15,26 Гц) | нельзя (не меньше 15,26 Гц) |
| 10 Гц | ровно: N=8, OCR=49999; N=64, OCR=6249 | нельзя (не меньше 15,26 Гц) | нельзя (не меньше 15,26 Гц) |
| 50 Гц | ровно: N=8, OCR=9999; N=64, OCR=1249 | ≈ N=1024, OCR=77: 50,08 Гц (0,16 %) | ≈ N=1024, OCR=77: 50,08 Гц (0,16 %) |
| 100 Гц | ровно: N=1, OCR=39999; N=8, OCR=4999; N=64, OCR=624 | ≈ N=256, OCR=155: 100,16 Гц (0,16 %) | ≈ N=256, OCR=155: 100,16 Гц (0,16 %) |
| 488 Гц | ≈ N=1, OCR=8196: 487,98 Гц (0,003 %) | ≈ N=64, OCR=127: 488,28 Гц (0,058 %) | ≈ N=32, OCR=255: 488,28 Гц (0,058 %) |
| 1000 Гц | ровно: N=1, OCR=3999; N=8, OCR=499 | ≈ N=64, OCR=62: 992,06 Гц (0,794 %) | ровно: N=32, OCR=124 |

Пояснения:

- Медленнее 30,52 Гц (прерывания) и 15,26 Гц (меандр) 8-битные таймеры не умеют. Медленные частоты на них собирают программно: прерывание 1000 Гц (N = 64, OCR = 124, ровно) и счётчик в обработчике (до 1000 для 1 Гц, до 100 для 10 Гц).
- 488 Гц ровно не получить ни на одном таймере: 8 000 000 / 488 не целое. Число 488 в курсе означает 488,28 Гц, переполнение Timer0 с делителем 64.
- Ровно 1000 Гц меандра из 8-битных таймеров даёт только Timer2 (делитель 32).

### Частоты ШИМ (Timer0, Timer2)

Частота ШИМ 8-битного таймера зависит только от делителя N: f_clk / (N · 256) в Fast PWM и f_clk / (N · 510) в Phase Correct. Число в OCR меняет заполнение, а не частоту.

| N | Fast PWM | Phase Correct |
|---|---|---|
| 1 | 31250 Гц | 15686,27 Гц |
| 8 | 3906,25 Гц | 1960,78 Гц |
| 32 (только Timer2) | 976,56 Гц | 490,2 Гц |
| 64 | 488,28 Гц | 245,1 Гц |
| 128 (только Timer2) | 244,14 Гц | 122,55 Гц |
| 256 | 122,07 Гц | 61,27 Гц |
| 1024 | 30,52 Гц | 15,32 Гц |

У Timer1 частоту ШИМ задаёт вершина TOP: f_clk / (N · (1 + TOP)) в Fast PWM. Например, режим 14, N = 8, ICR1 = 19999: ровно 50 Гц (сервопривод).
